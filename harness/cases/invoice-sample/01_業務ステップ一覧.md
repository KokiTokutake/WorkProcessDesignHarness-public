# 01. 業務ステップ一覧(WORKING1-2相当)

## 対象業務のスコープ

| 項目 | 内容 |
|---|---|
| 業務名 | 請求書作成業務 |
| 範囲(開始〜終了) | 「納品完了報告」〜「請求書の顧客受領確認」 |
| 対象部門・担当者 | 経理部・営業部 |
| 分析の目的 | 月次請求書作成業務(受注〜請求書発行)の可視化と改善案の検討 |
| 分析日 | 2026-07-10 |

**担当者(レーン)一覧**: 営業 / 経理 / 顧客

## ステップ一覧

| # | ステップ名 | 担当者 | 概要(1行) |
|---|---|---|---|
| A1 | 納品完了報告 | 営業 | 納品完了をメールで経理へ連絡する |
| A2 | 納品データ確認 | 経理 | メール本文から納品情報を確認しリスト化する |
| A3 | 顧客・金額の突合 | 経理 | 販売管理システムと納品リストを手動で突合する |
| A4 | 不明点の問い合わせ | 経理 | 金額不一致時に営業へ問い合わせる |
| A5 | 請求書作成 | 経理 | 請求対象リストから請求書(PDF)を作成する |
| A6 | 上長承認 | 経理 | 作成した請求書を上長が確認・承認する |
| A7 | 請求書受領・照合 | 顧客 | 承認済み請求書を受領し内容を照合する |

## メモ・気づき

- A2〜A4(納品データ確認〜問い合わせ)に経理の作業が集中しており、月末に負荷が偏っている。
- A4の問い合わせはA1の連絡が定型化されていれば発生自体を減らせる可能性がある。
