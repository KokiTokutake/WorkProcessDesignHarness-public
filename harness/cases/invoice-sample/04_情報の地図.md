# 04. 情報の地図(WORKING5相当)

## 情報一覧

| 情報・データ名 | 発生元(ステップ/システム) | 保管場所 | 参照するステップ | 更新頻度 | 備考 |
|---|---|---|---|---|---|
| 納品情報 | A1(営業のメール) | メールボックス(個人) | A2, A3 | 納品都度 | 書式が統一されておらず検索性が低い |
| 販売管理データ | 販売管理システム | 販売管理システム | A3 | リアルタイム | 経理は手動で参照・突合 |
| 請求対象リスト | A3 | 経理の共有フォルダ | A4, A5 | 月次 | 不一致行にフラグなし、目視確認 |
| 請求書(PDF) | A5 | 請求書発行システム/共有フォルダ | A6, A7 | 月次 | |

## 情報の流れ図(テキストベース)

```
納品情報(メール) → 経理が手動で確認・転記 → 請求対象リスト(突合済み) → 請求書(PDF) → 顧客
                                      ↑
                          販売管理システム(手動参照)
```

## 気づき

- 情報が「点在」していて探索コストが発生している箇所: 納品情報がメール本文に散在(A1→A2)。
- 二重入力・二重管理になっている箇所: 販売管理システムのデータを経理が手動で請求対象リストへ転記している。
- システム間で自動連携できていない箇所: 販売管理システムと請求書発行の間にAPI/CSV連携がなく、すべて人手を介している。
