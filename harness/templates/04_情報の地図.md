# 04. 情報の地図(WORKING5相当)

「業務の地図」(=ステップの流れ、01で作成済み)とは別に、業務の中で扱われる**情報・データ**が
どこで生まれ、どこを経由し、どこで使われているかを整理する。DX・デジタル化の前提として、
情報の流れの現状認識を持つことが目的(第1章「対立する情報システム部門と業務部門」参照)。

## 情報の流れ図(テキストベース)

矢印で発生元→経由→利用先を記述する(この内容がTO-BE設計時のシステム連携要件の元になる)。

```
例) 納品情報(メール) → 経理が手動転記 → 販売管理システム → 請求書作成
```
