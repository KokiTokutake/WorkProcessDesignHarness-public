# 02. 個別定義シート(WORKING3相当)

`01_業務ステップ一覧.md` の各ステップについて、このシートを1つずつ複製して記入する。
A4 1枚に収まる粒度を意識し、書く順序は **INPUT → DO → OUTPUT → トリガー → メモ**。
書き方の詳細は `../framework.md` の「2. 個別定義シートの書き方」を参照。

---

## ステップID: (例: A1)

| 項目 | 内容 |
|---|---|
| ステップ名 | |
| 担当者(レーン) | |
| INPUT | 処理に必要な情報・資材を具体名で |
| DO | 動詞+目的語で簡潔に |
| OUTPUT | 処理完了状態・ゴール |
| トリガー | 着手条件(例:「毎月末」「納品完了日」) |
| メモ | 例外処理・判断ポイントなど |
| ムダ時間タグ | 該当する場合のみ:探す時間 / 確認する時間 / 問い合わせる時間 / 判断待ち時間 |
